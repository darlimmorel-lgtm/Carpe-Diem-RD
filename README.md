# Carpe Diem Vision

Actúa como un equipo senior compuesto por un director creativo especializado en hospitality de lujo, diseñador UI/UX, desarrollador frontend experto en React y TypeScript, especialista en animaciones web, experto en conversión y consultor SEO local.

Tu misión es DISEÑAR Y CONSTRUIR una página web completa, premium, visualmente impactante y funcional para CARPE DIEM RD, restaurante, terraza, bar y lounge situado en Santo Domingo Este, República Dominicana.

No construyas una plantilla genérica de restaurante. Crea una experiencia digital con identidad propia, dirección de arte coherente, fotografías gastronómicas de alto nivel, animaciones cinematográficas elegantes y una experiencia de usuario diseñada para conseguir reservas, consultas de eventos y visitas al restaurante.

IMPORTANTE:
- Construye la web real dentro del proyecto, no te limites a describirla.
- Antes de modificar el proyecto, inspecciona su estructura, componentes y dependencias existentes.
- Si el proyecto ya contiene una implementación, reutiliza lo que sea útil y evita romper funcionalidades existentes.
- No inventes testimonios, premios, datos comerciales, disponibilidad de mesas ni funcionalidades supuestamente conectadas.
- Todo botón debe ejecutar una acción real y comprensible.
- Mantén un código limpio, reutilizable, accesible y preparado para futuras ampliaciones.
- Toda la experiencia debe estar en español, con precios en pesos dominicanos (RD$).

- Hora deseada.
- Número de personas.

- Nombre obligatorio.
- Teléfono obligatorio.
- Fecha obligatoria.
- Hora obligatoria.

- Fecha no anterior al día actual.

2. Construye un resumen de la solicitud.
3. Codifica correctamente el texto para una URL.

5. Incluye los datos introducidos en el mensaje.

“Hola, Carpe Diem RD. Me gustaría consultar una reserva.

Nombre: [nombre]
Teléfono: [teléfono]
Fecha: [fecha]
Hora: [hora]
Personas: [cantidad]
Ocasión: [ocasión]

G. SCROLL
